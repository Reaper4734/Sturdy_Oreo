# Eraser.io Feature Cloning Guide

This document maps the best features of Eraser.io (DiagramGPT) to our custom AI Canvas engine, utilizing **Mermaid.js** and the **3.1 Flash Lite** model over WebSockets.

---

## 1. Multi-Modal Editing (Side-by-Side View)
**Eraser.io Feature:** Users can drag-and-drop elements on a canvas, but they can also open a side panel to edit the raw "diagram-as-code" directly.
**Our Mermaid.js Implementation:** 
*   In Flutter, add a toggle switch: `[Visual View | Code View]`.
*   When flipped to `Code View`, reveal a simple text editor containing the raw Mermaid markup generated by the AI.
*   If the user edits the Mermaid text manually (e.g., fixing a typo), the diagram instantly re-renders when they switch back.

## 2. Cloud Architecture Icons & Theming
**Eraser.io Feature:** Cloud diagrams look incredibly professional because they use native AWS/GCP/Azure icons.
**Our Mermaid.js Implementation:**
*   **System Prompt Update:** We will instruct 3.1 Flash Lite to utilize FontAwesome icons inside the Mermaid diagrams. 
*   *Prompt Example:* "When drawing databases or servers, use FontAwesome icons in your Mermaid syntax, like `A[fa:fa-database UserDB] --> B[fa:fa-server API]`."
*   This instantly elevates the visual quality of the raw diagrams.

## 3. Conversational Refinement (The "Copilot")
**Eraser.io Feature:** You don't have to rewrite the whole diagram if it's wrong. You just tell the AI what to change.
**Our Mermaid.js Implementation:**
*   The Flutter app stores the *current* Mermaid code in its local state. 
*   When the user types *"Add a Redis Cache between the API and the Database"*, Flutter sends the payload:
    ```json
    {
      "prompt": "Add a Redis Cache between the API and the Database.",
      "current_code": "graph TD;\n API-->Database;"
    }
    ```
*   **3.1 Flash Lite** surgically updates the code to `graph TD;\n API-->RedisCache;\n RedisCache-->Database;` and streams it back.

## 4. Code-to-Diagram Generation
**Eraser.io Feature:** Paste a block of Python or Java code, and Eraser instantly draws a Sequence Diagram or Flowchart.
**Our Mermaid.js Implementation:**
*   Since 3.1 Flash Lite has a massive context window and understands code natively, we simply allow the user to paste code into the Canvas chat.
*   The System Prompt handles the rest: *"You are an AI architect. Convert the user's raw code into a Mermaid Sequence Diagram (`sequenceDiagram`)."*

## 5. Supported Diagram Modalities
Eraser explicitly supports multiple diagram types. We will configure 3.1 Flash Lite to default to these specific Mermaid syntaxes based on the user's prompt:
1.  **Architecture:** Default to `graph TD` or `flowchart LR`.
2.  **User Flows:** Default to `sequenceDiagram`.
3.  **Database Design:** Default to `erDiagram`.

---

## The Master System Prompt (For the Backend)
To make 3.1 Flash Lite behave exactly like Eraser.io, we will inject this exact prompt into the `/canvas/stream` endpoint:

> "You are an expert Cloud Architect and Diagram Engine (similar to Eraser.io). 
> You output STRICTLY in Mermaid.js syntax wrapped in ```mermaid``` blocks. 
> - Use `sequenceDiagram` for logic flows.
> - Use `flowchart TD` for architectures. 
> - Use FontAwesome icons (e.g., `fa:fa-database`) to make diagrams look professional.
> Do not output markdown text outside of the mermaid block unless explicitly asked to explain the diagram."
